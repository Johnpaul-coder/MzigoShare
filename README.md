# MzigoShare — Shared Agricultural Logistics Engine

> Pooling small harvests into full truckloads to unlock agricultural value addition.

## Opening & Running in VS Code
1. Extract this ZIP archive and open the `mzigoshare` folder in **Visual Studio Code** (or double-click `mzigoshare.code-workspace`).
2. Open the integrated terminal (`Ctrl + `` `) and install dependencies:
   ```powershell
   npm install
   ```
3. *(Optional)* Copy `.env.example` to `.env` and add your Firebase credentials. If left unconfigured, MzigoShare runs out of the box in real-time local sync mode.
4. Start the development server:
   ```powershell
   npm run dev
   ```
